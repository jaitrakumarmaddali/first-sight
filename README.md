# FIRST SIGHT

 AI that sees what you're working on and helps before you ask.

 A proactive AI workspace for students that observes meaningful work activity, detects struggles, and provides contextual assistance before the student has to ask.

---

🚀 Overview

Students don't always know when they are stuck.

They may:

- Run the same code repeatedly
- Make the same mistake in an assignment
- Struggle with the same exam topic
- Spend too much time on one problem
- Repeatedly attempt something without progress

Traditional AI assistants wait for the student to ask:
Student → Ask AI → AI Answers
